## Project 2: Temperature Converter
Uses math to swap temperatures between Farenheight, Celsius, and Kelvin
### features
- safety warning that tells user what units to use
- if statements
- do-while loops
### use
compile tempconverter.cpp and run it with g++. type confirm to get past safety screen. type a temperature and then any of the following, F for farenheight, C for celsiues, and K for kelvin.
